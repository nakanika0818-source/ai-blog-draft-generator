# トラブル対処

エラーの内容は、L列またはダイアログに表示されます。下記の表のうち「実機で発生」と書いた項目は、今回の作業中に実際に起きたものです。それ以外のClaude APIとWordPress APIの項目は公式資料に基づくもので、実機では起きていません。

## メニュー・シート

| 症状 | 原因と対処 |
|---|---|
| `記事生成` メニューが出ない | スプレッドシートを再読み込みします。`Menu.gs` の貼り付け漏れも確認します |
| `列 N の見出しが…` | 列の順番か見出しが変わっています。元に戻します |
| `別の見出し…があるため中止` | 既存シートのA〜N列に別の内容があります。列を移すか、新しいシートを使います |
| `一度に処理できるのは1行だけ` | 1行だけ選択します |
| `別の処理が実行中` | 完了を待ちます。他の人が実行中の場合もあります |
| `生成中です` / `投稿処理中です` | 完了を待ちます。7分以上経っていれば再実行できます |
| 権限の承認画面が出る | 初回に必要です。Googleの警告が出た場合は、自分のスクリプトであることを確認してから進めます |
| 設定したはずのプロパティが `未設定` になる（実機で発生） | 別のスプレッドシートのApps Scriptを開いている可能性があります。スプレッドシートの名前を確かめ、そのシートの **拡張機能 > Apps Script** から開き直します |
| 保存すると構文エラーになる（実機で発生） | 貼り付けの途中で、クリップボードが別の文字に上書きされた可能性があります。ファイルの中身を全部消し、元のファイルからコピーし直して貼ります |
| `生成済みの記事があるため上書きしません`（実機で発生） | 正常な動作です。記事を消さないように止めています。作り直す場合は **選択行を再生成（上書き確認あり）** を使います |

## 生成（Claude API）

| L列の内容 | 原因と対処 |
|---|---|
| `ANTHROPIC_API_KEY が未設定` | スクリプトプロパティを設定します |
| `HTTP 400` で `anthropic-workspace-id` を求められる（実機で発生） | ワークスペースに紐づかないキーです。Consoleの **Settings > Workspaces** のID列にある `wrkspc_` で始まるIDを、`ANTHROPIC_WORKSPACE_ID` に設定します |
| `HTTP 400 invalid_request_error` | メッセージを確認します。利用上限に達した場合もこのエラーです。`fallbacks` や `anthropic-beta` に関する内容なら `CLAUDE_FALLBACKS=off` を試します |
| `HTTP 401 authentication_error` | キーが誤り、失効、または期限切れです。発行し直します |
| `HTTP 402 billing_error` | Consoleで支払い情報を確認します |
| `HTTP 403 permission_error` | キーの権限やワークスペースの設定を確認します |
| `HTTP 404 not_found_error` | `CLAUDE_MODEL` が誤りか、利用できないモデルです。Claude接続テストで確認します |
| `HTTP 429 rate_limit_error` | 自動で再試行します。続く場合はConsoleで上限を確認します |
| `HTTP 500` / `529` | 一時的な障害です。自動で再試行します。続く場合は時間を置きます |
| `実行時間が足りないため中止` | 応答が遅い場合に起きます。再実行するか、`CLAUDE_EFFORT` を下げます |
| `出力が途中で終了（max_tokens到達）` | `CLAUDE_MAX_TOKENS` を増やします |
| `モデルが生成を拒否` | キーワードを見直します |
| `JSONが不正` / `JSONではありません` | 再実行します。続く場合はrequest_idを控えて確認します |
| `本文が N 字です` | 指定字数に収まりませんでした。再実行します。続く場合は `CLAUDE_EFFORT` を上げます |
| `本論のH2が…` / `最後の見出しが…` | 構成違反です。再実行します |
| `HTMLタグ` / `Markdown記号が含まれて` | 形式違反です。再実行します |
| `文体サンプルと一致する文があります` | サンプルの文をそのまま使っています。再実行します |

サポートへ問い合わせる場合は、request_idを伝えます。APIキーは伝えないでください。

## 投稿（WordPress）

| L列の内容 | 原因と対処 |
|---|---|
| `未設定です: WP_...` | スクリプトプロパティを設定します |
| `WP_BASE_URL は https://…` | `https://` で始まるURLにします。URLに認証情報を含めないでください |
| `HTTP 301/302 リダイレクト` | `www` の有無や末尾のパスを確認し、リダイレクト先の正しいURLにします |
| `HTTP 401` | ユーザー名かアプリケーションパスワードが誤りです。サーバーがAuthorizationヘッダーを削除している場合もあります |
| `HTTP 403 rest_cannot_create` | そのユーザーに投稿権限がありません。セキュリティプラグインがREST APIを止めている場合もあります |
| `HTTP 404 rest_no_route` | REST APIが無効か、パーマリンク設定により `/wp-json/` が使えません。サイト管理者に確認します |
| `HTTP 5xx` / 通信エラー / `JSONではありません` | `投稿結果不明` になります。[使い方](02_使い方.md)の手順で確定します |
| `statusが「publish」です` | 下書き以外で作成されました。**至急WordPress管理画面で確認してください。** サイト側のプラグインが変更している可能性があります |
| `本文が N 字です`（送信前） | 編集後の本文が条件を外れています。修正してから投稿します |

## キーが漏れた場合

1. Claude ConsoleまたはWordPress管理画面で、該当のキーを直ちに失効させます。
2. 新しいキーを発行し、スクリプトプロパティを更新します。
3. Consoleの利用状況を確認します。

## 実送信を止めたい場合

スクリプトプロパティの `WP_SEND_ENABLED` を削除します。次回の実行から送信されなくなります。
