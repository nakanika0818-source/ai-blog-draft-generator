### テストとレビューで見つかり修正した不具合

| 不具合 | 修正 |
|---|---|
| 認証情報のBase64化で文字コードを指定しておらず、日本語のユーザー名で認証に失敗する恐れがあった | UTF-8を明示 |
| 日本語本文を送るPOSTで文字コードを指定していなかった | `charset=utf-8` を明示 |
| 投稿IDを消してURLだけ残した行を、再投稿できてしまった | URLがある行も投稿しない |
| `fact_check_items` の不正な要素で例外になり、失敗工程が誤って記録される恐れがあった | 内容検証の違反として扱う |
| 空のタイトルで下書き検索すると、全件を検索してしまった | 検索前に止める |
| 機械検出が、労務の法令に関する一部の語句を拾えなかった | 検出パターンに追加 |
| 更新日時の判定で `instanceof Date` が失敗すると、処理中の行を中断扱いにする恐れがあった | 実行環境に依存しない判定へ変更 |
| 書き込み順のテストが、ステータスを本文より先に書く不具合を見逃していた | 最初に `生成済み` を書く位置を確かめるようテストを強化 |
